# Neo-Soul Keys

A daily 30-minute neo-soul keyboard practice app: warm-up, lesson, chord changes, groove loop and riff.

- Live at https://skaben82.github.io/neo-soul-keys/
- Use Chrome on a Mac to connect a MIDI keyboard (Safari and iPad browsers can't hear MIDI keyboards).
- Progress syncs between devices through Supabase once you sign in with an emailed link.
